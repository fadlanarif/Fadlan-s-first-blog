## 📌 Project Overview & Purpose
This project is built to showcase a professional digital portfolio while demonstrating an entrepreneurial mindset in project execution, clean organization, and user-focused value creation. The blog serves as a personal branding platform to share tech insights and academic progress.

### Key Features
* **Multi-Page Navigation:** Seamlessly browse between Home, About, Blog, and Contact pages.
* **Sample Tech Articles:** Features 2 distinct, thoughtfully written blog posts regarding software development and GitHub practices.
* **Responsive Web Design:** Fully optimized layout using CSS Media Queries for desktop, tablet, and mobile phone viewports.
* **Clean Repository Structure:** Organized codebase with dedicated styling directories.

---

## 🛠️ Technologies Used
* **HTML5:** Structuring the website layout and content semantic tags.
* **CSS3:** Custom typography, color palettes, modern card-based layouts, and responsive media queries.
* **GitHub Pages:** Cloud deployment and hosting infrastructure.
